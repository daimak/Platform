# Platform

Система управления собственной жизненной эволюцией. Основа — обычные файлы: система должна сохранять не только результаты работы, но и контекст появления этих результатов.

## Как открыть

Главный интерфейс: `eVo/dashboard/index.html` в браузере.

Отдельного сервера приложения нет. Vue-каркас в `Interface/` — шаблон, не текущий Command Center.

## Куда идти дальше

- текущий фокус: `Memory/Context/CURRENT.md`
- фактическая карта репозитория: `Docs/Map.md`
- принципы: `Core/Principles.md`
- архитектура: `Docs/Architecture/README.md`
- сводка разговора о Platform / eVo: `Memory/Archive/Reports/Report-2026-10-23-Platform-eVo.md`
- журнал изменений: `CHANGELOG.md`

## Каталоги

- Core — принципы, глоссарий, ADR
- eVo — стюард и Command Center (дашборд Estate)
- Memory — долговременный контекст
- Interface — способы взаимодействия (каркас Vue)
- Workspace — проекты и артефакты пользователя
- Modules — предметные области
- Vision — концепты и визуальное направление
- Tools — скрипты и протокол Barrymore
- Docs — документация платформы
- RFC — предложения изменений
- Notes — входящий поток и открытые вопросы
