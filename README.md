# Platform

Система управления собственной жизненной эволюцией. Основа — обычные файлы: система должна сохранять не только результаты работы, но и контекст появления этих результатов.

**Текущая версия: 1.8.3** — [заметки релиза](Docs/Releases/v1.8.3.md).

## Как открыть

Главный интерфейс: после однократной установки локального автозапуска откройте `http://127.0.0.1:8765`. Установщик: `tools/barrymore/install-dashboard.ps1`.

Локальный сервер стартует при входе пользователя в Windows, проверяет источники при открытии страницы и обновляет Morning Brief только при изменениях. История задач хранится рядом с инженерным планом в `Memory/Engineering/Tasks/`.
