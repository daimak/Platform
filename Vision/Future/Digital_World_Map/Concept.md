# Digital World Map Concept

Status: Future Vision

Date: 2026-07-24

---

# Origin

Platform begins as a small digital estate.

The first goal is not to build a planet.

The first goal is to create a living foundation capable of growth.

eVo may evolve beyond a dashboard into a spatial interface for managing a growing digital world.

---

# Core Idea

Digital World Map is not a map of Earth.

It is a map of a created digital civilization.

The user does not explore physical territory.

The user explores:

- systems;
- knowledge;
- projects;
- agents;
- resources;
- connections;
- evolution.

---

# Visual Metaphor

A world of floating islands.

The central island represents Platform Core.

On the central island stands the main castle:

- Foundation;
- Architecture;
- Rules;
- Memory;
- Current Reality.

Around it appear smaller islands.

Each island represents a domain or capability.

---

# First Islands

## Barrymore Island

The keeper's observatory.

Purpose:

- system state;
- reports;
- history;
- context preservation.

---

## Hunter at Core Citadel

For now, Hunter is based in the Core Citadel rather than on a separate island.

Purpose:

- external opportunities;
- jobs;
- orders and market signals;
- connections and leads for the whole archipelago;
- information that helps relevant islands assess the production capacity needed
  to pursue an opportunity.
- urgent focus on vacancies with a realistic fast hiring path and income sources
  with a short time to first payment;
- grouping, verification, freshness tracking, storage, and ranking by time to
  money, likelihood, fit, complexity, and source reliability.

Hunter's direct integration with AI Sandbox on Estate is planned. A separate
Hunter Island may be considered later if the role and its capabilities grow
enough to need a dedicated domain.

The Core Citadel cabinet can receive and store user assignments locally. This
does not mean an autonomous Hunter agent, live vacancy collection, or automatic
refresh is already running.

---

## Memory Library

The archive.

---

# Interaction Concept

The user does not open pages.

The user explores the world.

Hovering over an island:

- zooms into the location;
- reveals buildings;
- shows current state;
- displays connections;
- opens paths to related areas.

The world itself becomes the interface.

---

# Evolution Path

Estate → Village → City → Country → Planet

The interface must support growth.

A small system should not look empty.

A large system should not become chaotic.

The same metaphor must scale.

---

# Principle

The purpose is not to create a beautiful map.

The purpose is to create a way to understand a growing digital civilization.
