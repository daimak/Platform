# Estate Interactive Callouts V2.1 — спецификация коллаутов карты

**СТАТУС: черновик, требует решения владельца.** Конвенции V2.1 в репо нет: в
`Vision/Estate/Decomposition/` это единственный файл (до 2026-10-30 — пустая заглушка,
аудит R7), предыдущей версии V2.0 не существует. Ниже — минимальная спецификация того,
что **реально реализовано** в `eVo/dashboard/index.html` (+ `app.js`, `languages.js`,
`style.css`) на момент 2026-10-30; вопрос «что должно стать конвенцией V2.1» — открыт
(см. «Открытые вопросы»).

## 1. Коллаут острова = hotspot (маячок + hover-карточка)

Реализовано как блок `div.island-hotspot` внутри слоя карты:

- позиционирование — inline-стилем в процентах от карты (`top`/`left`); единственная
  аномалия — `tradingQuarter` с `left: calc(54.3% + 100px)`;
- `data-island="<ключ>"` — единственный программный контракт: по нему `app.js` открывает
  модалку и берёт тексты из словаря `languages.js` (`lang.islands[ключ]`);
- модификатор `tooltip-down` (перевёрнутая выноска) стоит только на `mainEstate` и
  `holmesStudy`; остальные маячки используют направление по умолчанию.

## 2. Маячок (beacon)

- `div.beacon-core` + `span.beacon-icon` с emoji-иконкой острова (🏰 🔍 ⚙️ 🧭 🧪 📚 🗄️ ⚓ 🏺);
- цветовая роль — классом: `beacon-gold` (ядро), `beacon-rose` (аудит/Холмс),
  `beacon-amber` (workshop, tradingQuarter), `beacon-cyan` (navigator, harbor),
  `beacon-emerald` (aiSandbox), `beacon-purple` (memoryLibrary, knowledgeArchive).

## 3. Hover-карточка (выноска/подпись)

`div.island-hover-card` с четырьмя текстовыми слотами:
`hover-badge` (роль узла, напр. «CORE NEXUS»), `hover-title` (ЗАГЛАВНОЕ имя),
`hover-subtitle` (описание по-русски), `hover-action-hint` (подсказка действия).
Тексты в карточках захардкожены в `index.html` (RU) и дублируются словарями
`languages.js` — два источника правды, между ними нет проверки синхронности.

## 4. Клик = модалка

Клик по hotspot читает `data-island`, `app.js` подставляет `badge/title/subtitle` из
словаря и строит тело модалки через `buildIslandContentHTML` (switch по ключу:
`mainEstate`, `barrymore`, `workshop`, `aiSandbox`, `memoryLibrary`, `navigator`,
`holmesStudy`, `tradingQuarter` и др.). На карте 9 hotspot'ов `data-island`; десятая
кликабельная точка — HTML-плашка Барримора, сделанная отдельно (не hotspot).
