# TASK 1 — Buildings as Functional Objects

## ель

аучиться превращать отдельное здание на карте в настоящий интерактивный промышленный объект eVo.

## MVP одного здания

- [ ] ыделить здание из исходного изображения.
- [ ] Сохранить его отдельным PNG с прозрачностью.
- [ ] азместить поверх фонового мира.
- [ ] еализовать hover-состояние.
- [ ] ри наведении слегка подсвечивать здание.
- [ ] оказывать компактную информационную карточку / меню.
- [ ] еализовать click.
- [ ] о клику открывать полноценный интерфейс здания.
- [ ] еализовать хотя бы одно реальное действие внутри интерфейса.
- [ ] еализовать создание задачи.
- [ ] еализовать изменение статуса задачи.

## ринцип

Сначала полностью довести до рабочего состояния  здание.

Только после этого переносить архитектуру на остальные здания.

# TASK 2 — Living World

## ель

остепенно добавить в Estate небольшие независимые движения,
которые создают ощущение живого мира.

## ервый эксперимент

### Bird

инимальная функциональность:

- [ ] тдельный визуальный asset птицы.
- [ ] оявление птицы в сцене.
- [ ] лавный пролёт через сцену.
- [ ] счезновение / вылет за пределы сцены.
- [ ] овторный случайный пролёт.

икакой сложной логики поведения на первом этапе.

## альнейшая эволюция

осле успешной птицы:

- облака;
- туман;
- волны;
- окна зданий;
- водопады;
- корабли;
- события, влияющие на движение объектов.

# IMPORTANT PRINCIPLE

е пытаться сразу реализовать весь живой мир.

аждый новый эффект должен сначала существовать как
маленький самостоятельный эксперимент.

Сначала:

bird

отом:

bird + clouds

отом:

bird + clouds + fog

 так далее.
