# 1. Relocation Strategy

Рассмотрен сценарий переезда в Узбекистан.

Исходные условия:

- загранпаспорт есть;
- физическая возможность выезда есть;
- запрета на выезд по проверенным исполнительным производствам нет;
- доступный стартовый капитал ограничен.

Основная идея:

Не просто сменить место проживания, а открыть новый рынок и снять текущие ограничения.

---

# 2. Landing Phase (7-90 days)

Первые дни рассматриваются как этап приземления:

Цели:

- найти безопасную базу;
- минимизировать расходы;
- собрать локальную информацию;
- создать первые денежные потоки.

Первичные направления:

- временная работа;
- курьерские сервисы;
- кухня;
- склад;
- сборка заказов;
- локальные подработки.

Параллельно:

- активный IT-поиск;
- удалённые заказы;
- международные возможности.

---

# 3. IT Strategy

Основной принцип:

Не ограничиваться одним рынком.

Направления:

- IT support;
- удалённое администрирование;
- разовые технические работы;
- международные площадки.
