**Дата:** 2026-10-25
**Исполнитель:** агент (ZCode), по протоколу `Memory/Engineering/`
**Основание:** указание пользователя (E-001 — полный read-only аудит; E-007 — синтез; E-008 — итоговый отчёт)
**Доказательная база:** `Memory/Engineering/FINDINGS.md` §1–§11 (пути:строки), журнал `Memory/Engineering/LOG.md` (E-000…E-008, S-3)

---

## 1. Резюме

Platform/eVo — персональная «операционная система эволюции» на обычных файлах: markdown + статический UI. Единственный реально работающий артефакт — статический дашборд `eVo/dashboard/index.html` (карта 9 островов, RU/EN, задачи в localStorage). Сервера, API, БД, CI и агентного runtime нет: Barrymore существует как протокол и git-скрипты. Самая ценная работающая подсистема — Memory, но с конкурирующими точками входа. До реструктуризации 2026-10-25 репозиторий смешивал четыре контура: систему, пользовательские эксперименты, чужой проект и архивы/кэши.

## 2. Метод и охват

Read-only аудит: прочитано ~75 файлов (весь текстовый корпус, кроме Vision-хвостов и кэша Graphify); побайтовые сравнения дубликатов (diff/cmp); git-диагностика (log, ls-files, grep по HEAD и origin-ссылкам). Скрипты и UI не запускались — выводы о поведении из чтения кода. Незакрытый остаток перечислен в FINDINGS §11.3.

## 3. Ключевые находки (доказательства в FINDINGS)

1. **Точки входа.** Запускаемое: dashboard (статичен, без единого fetch), 3 PowerShell-скрипта (evo-check, evo-save, barrymore/execute), Python-эксперимент `Workspace/main.py`. `Interface/` — нетронутый шаблон Vite/Vue. `bootstrap.ps1` ни разу не запускался.
2. **Связи слоёв.** Фактически отсутствуют в коде: dashboard не читает Memory (Morning Brief — статическая строка), Interface ничего не читает, Modules пуст. Слои существуют в документах, не в коде — прямое следствие: нарушение ADR-002 («интерфейс обнаруживает сущности, а не хардкодит»).
3. **Дублирование.** Побайтовые: `eVo/dashboard/Backup/` (7 файлов), два Handoffs, два Archive CURRENT, `evo-save.ps1.backup`, `.env`-пара. Конкурирующие механизмы: два CURRENT, три места решений (+ADR из bootstrap), две нумерации принципов (Core P1–P11 vs Inbox P9–P21), три «утренних брифа» (свой Morning Brief, сторонний claude-chief-of-staff, скилл chief-of-staff).
4. **Barrymore.** Исполняется только `execute.ps1` (git add+commit+отчёт). Morning Brief, Kingdom Status, агентная команда — только документы; dashboard ссылался на несуществующий ADR-0001.
5. **Безопасность.** Реальные ключи (LangSmith, FreeLLMAPI) лежали в `Workspace/main.py` и попали в локальный коммит. **Исправлено в тот же день (S-3):** ключи — в `Workspace/.env` (untracked), коммит переписан до пуша, в Git-истории ключей нет. Ротация ключей — за пользователем.
6. **Противоречия документов.** Версии v0.1/0.2/0.1.0-alpha/v1.8.1; четыре модели веток; `RFC/` описан, но отсутствовал; root drift (SYSTEM_SUMMARY, claude-chief-of-staff); дашборд имитирует живые статусы («процессы: 5», «пульс 1.2с»); mojibake в двух файлах; ~30 МБ PNG и кэш Graphify под версионным контролем.

## 4. Исправления, выполненные 2026-10-25

- **S-3 (безопасность):** секреты из кода и истории Git устранены; `Workspace/.env.example` — шаблон; `main.py` читает окружение.
- **Реструктуризация контура (RFC-001, коммиты `fbffd54`, `032eb57` на ветке `feature_1.8.2`):** claude-chief-of-staff → `C:/Work/reference/`; Backup (PNG) → `C:/Work/Platform-archive/`; `eVo/dashboard/Backup/` и `Interface/` удалены; graphify-out не отслеживается; дубли удалены; `Workspace/CURRENT.md` → `notes-memory-design.md`.
