Что решили

Локализация должна быть архитектурной, а не "ручной".

Не так:

document.getElementById(...)

Не так:

if(lang=="ru") ...

А через полноценный слой i18n.

Подготовлено
dashboard/
└── locales
    ├── ru
    │   └── dashboard.json
    ├── en
    │   └── dashboard.json
    └── fr
        └── dashboard.json

fr оставляем как тест того, что система умеет работать с произвольным количеством языков.

Следующая задача

Написать собственный минимальный движок локализации.

Появится:

dashboard

app.js
i18n.js        ← новый файл

locales/

Именно i18n.js будет:

загружать словарь;
переключать язык;
переводить страницу.
После этого

Переделаем HTML.

Вместо

<h3>History</h3>

будет

<h3 data-i18n="history.title"></h3>

То есть HTML вообще перестанет содержать русский или английский текст.
