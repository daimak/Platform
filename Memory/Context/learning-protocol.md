# Learning Protocol

**Обязательный цикл обучения**

1. **Выполнение** – выполнить небольшой завершённый технический шаг.
2. **Фиксация** – зафиксировать цель, действия, результат, новые понятия, ограничения, открытые вопросы.
3. **Проверка понимания** – попросить пользователя объяснить понятия своими словами или ответить на контрольные вопросы.
4. **Коррекция** – разобрать ошибки и, при необходимости, повторить проверку.
5. **Практическое закрепление** – предложить небольшое самостоятельное действие, проверяющее навык.
6. **Второе подтверждение** – проверить результат практического действия.
7. **Переход дальше** – продолжать только после подтверждения понимания и практического результата. При усталости или неподготовленности сохранить точку остановки.
8. **Возобновление** – в начале следующей сессии кратко напомнить, что уже изучено, какие навыки есть и какой следующий шаг ожидает выполнения.

*Документ служит короткой карточкой; объём фиксируется согласно масштабу задачи.*
