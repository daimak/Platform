# Learning & Agent Management Plan (2026‑10‑19)

## 1. Цикл обучения (протокол)
1️⃣ **Выполнение** – небольшая завершённая задача (например, добавить запись в `Memory/Context`).
2️⃣ **Фиксация** – цель, действия, результат, новые понятия, ограничения, открытые вопросы.
3️⃣ **Проверка понимания** – пользователь объясняет понятия своими словами, отвечает на контрольные вопросы.
4️⃣ **Коррекция** – уточнение ошибок, повтор проверки.
5️⃣ **Практическое закрепление** – самостоятельное действие (второй запрос к Gemini, скрипт, etc.).
6️⃣ **Второе подтверждение** – проверка результата действия.
7️⃣ **Переход дальше** – продолжаем только после подтверждения; при усталости фиксируем точку остановки.
8️⃣ **Возобновление** – в начале следующей сессии кратко резюмировать пройденное и обозначить следующий шаг.

## 2. Инструменты для работы с агентами
| Инструмент | Назначение | Как задействовать |
|------------|------------|-------------------|
| **Antigravity CLI (`agy`)** | Управление проектом, slash‑команды, суб‑агенты | `agy --help`, `agy /plan`, `agy /goal` |
| **Суб‑агенты** (`self`, `research`) | Параллельные контексты (выполнение, поиск) | `invoke_subagent`, `send_message` |
| **Skills** (`automation`, `generative_ui`, etc.) | Пакетные наборы правил, UI‑виджеты, планировщики | `agy skill list`, `agy skill enable <name>` |
| **MCP сервер** | Обмен сообщениями между агентами | `agy mcp start`, `agy mcp status` |
| **Slash‑команды** (`/plan`, `/goal`, `/schedule`, …) | Быстрый запуск типовых сценариев | в чате, напр. `/plan` |
| **PowerShell / Windows** | Запуск скриптов, git, node, python | `run_command` в агенте |
| **Тулзы** (`view_file`, `run_command`, `write_to_file`, `schedule`, …) | Прямой доступ к ФС, git, таймерам | вызываются через агентный API |

## 3. Как интегрировать инструменты в цикл обучения
1. **Исследование** – `research`‑агент + `view_file`, `search_web` → собрать инфо.
2. **Планирование** – `/plan` → сформировать план (шаги 1‑8).
3. **Выполнение** – `run_command` + скрипты.
4. **Фиксация** – `write_to_file` → запись в `Memory/Context`/`Sessions`.
5. **Отслеживание** – `schedule` (таймер/cron) → напомнить о проверке.
6. **Ревью** – `send_message` к `self`‑агенту → обратная связь.

## 4. План дальнейшего обучения (рекомендации)
| Тема | Цель | Практика | Ожидаемый результат |
|------|------|----------|----------------------|
| **FreeAllAPI** | Понимать запросы к Gemini через посредника | `curl`‑запрос к `https://api.freeallapi.com/v1/gemini` | Умение делать запросы из кода без Playground |
| **Интеграция в Platform Evo** | Подключить Gemini‑клиент к бекенду | Добавить модуль `geminiClient.js` | Рабочая функция `callGemini(messages)` |
| **UI‑виджеты** | Показать ответы модели в dashboard | Компонент Vue/React, привязка к `geminiClient` | Веб‑страница выводит ответ в модальном окне |
| **Автоматизация экспериментов** | Планировать серию запросов, сохранять результаты | `/automation` → cron‑задача, запись в `Memory/Experiments` |
| **Продв. работа с агентами** | Создать собственный skill / plugin | Написать skill `my‑tasks` (добавление задач) | Файл `my‑tasks.md` в `skills/`, активирован в проекте |

## 5. Как проводить ревизию текущих агентных настроек
1. `agy subagent list` – список активных суб‑агентов.
2. `agy skill list --enabled` – проверка включённых skills.
3. `agy mcp status` – статус MCP‑сервера.
4. `agy slash list` – доступные slash‑команды.
5. `agy memory snapshot create today‑snapshot` – создать snapshot текущей памяти.
