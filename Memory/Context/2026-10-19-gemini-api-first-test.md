# 2026-10-19 Gemini API – первый тест

**Цель эксперимента**
- Проверить возможность отправки тестового запроса к Google Gemini через FreeAllAPI Playground, используя API‑ключ Google AI Studio (Free tier).

**Ключ**
- Найден API‑ключ в Google AI Studio с тарифом **Free tier** (значение не сохраняется).

**Провайдер / посредник**
- FreeAllAPI (FreeAllAPI Playground) – использован как промежуточный сервис для отправки запросов к модели Gemini.

**Выбранные модели**
- `gemini-pro` (по умолчанию в Playground).

**Отправленный запрос (русский язык)**
```text
Привет, помоги спроектировать архитектуру API для Platform Evo.
```

**Полученный ответ**
> "Привет! Конечно, давайте начнём…" (полный ответ содержит предложения по структуре эндпоинтов, аутентификации, схемы запросов/ответов и примеры кода).

**Вывод**
- Запрос через Playground успешно отправлен, ответ получен.

**Термины**
- модель, API, API‑ключ, провайдер/посредник, Playground.

**Что ещё НЕ проверено**
- Точная использованная модель (в Playground выбиралась `gemini-pro`, но конкретный идентификатор не зафиксирован).
- Ограничения квоты и доступность в продакшене.
- Наличие единого API‑эндпоинта и интеграция ключа FreeAllAPI в код Platform Evo.
- Прямая работа Gemini API из кода приложения.
