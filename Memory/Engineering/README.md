# Engineering

Инженерный журнал работы над Platform Evo: фиксация фактически выполненных действий, подтверждённых результатов исследований, плана и живой сводки для возобновления работы между сессиями и чатами.

Каталог создан 2026-10-25 по решению пользователя (см. LOG.md, E-000).

## Файлы

| Файл | Роль | Режим обновления |
|---|---|---|
| `STATE.md` | Живая сводка для возобновления работы | Переписывается в конце каждой сессии |
| `LOG.md` | Журнал фактически выполненных действий | Append-only, без исключений |
| `FINDINGS.md` | Результаты исследований с доказательствами | Дополняется; статусы уточняются корректировками |
| `PLAN.md` | Этапы и задачи аудита | Статусы и состав обновляются |

## Правила

1. **Источник истины — реальные файлы репозитория и Git**, не записи этого каталога. При расхождении записи и файла/Git верить файлу/Git; расхождение фиксируется записью в `LOG.md`.
2. `LOG.md` — append-only. Прошлые записи не исправляются и не удаляются. Ошибка в прошлой записи закрывается корректирующей записью со ссылкой на неё.
3. Каждый факт в `FINDINGS.md` имеет статус `ПОДТВЕРЖДЕНО / ПРЕДПОЛОЖЕНИЕ / НЕ ПРОВЕРЕНО` и, по возможности, доказательство: путь:строки, команда или хэш коммита.
4. `PLAN.md` — план, а не разрешение на выполнение. Любое действие выполняется только по явному указанию пользователя.
5. Архитектурные решения фиксируются в существующем `Memory/Decisions/` (формат D-0xx). Параллельная система решений здесь не создаётся.
6. Записи не выдумывают даты, команды, номера строк и доказательства. Непроверенное помечается явно.
7. Время — локальное, формат `YYYY-MM-DD HH:MM`.
8. Изменение файлов вне `Memory/Engineering/` — только по явному указанию пользователя (обновление `Docs/Map.md` и `CHANGELOG.md` — после отдельного согласования).
