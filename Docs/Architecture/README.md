# Архитектура платформы eVo

> Версия: 0.2

## Назначение

Этот документ является точкой входа в архитектуру проекта eVo.

Подробные документы:

- Задуманная структура каталогов: [Structure.md](Structure.md)
- Фактическая карта репозитория: [../Map.md](../Map.md)
- Архитектурные принципы: [Principles.md](Principles.md)
- Архитектурные решения: [Decisions.md](Decisions.md)

Слои системы (ядро / модули / знания) описаны отдельно: `Core/Architecture.md`. Это другой уровень, не дубль этого индекса.

## Главный принцип

eVo должен сохранять не только результаты работы, но и контекст появления этих результатов.

Любой компонент проекта должен отвечать на вопрос:

"Почему это существует?"
