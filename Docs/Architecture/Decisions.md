# Архитектурные решения eVo

## ADR-001: Единая политика кодировки

Дата: 12.07.2026

Статус: Принято

## Контекст

Проект eVo содержит большое количество документации, конфигураций и автоматизации.

Ошибки кодировки могут привести к повреждению контекста системы и потере читаемости артефактов.

## Решение

В проекте используется UTF-8 как единая кодировка всех текстовых файлов.

Правила:

- Markdown-файлы создаются и редактируются через инструменты с поддержкой UTF-8.
- PowerShell-скрипты должны явно задавать UTF-8 для вывода.
- Автоматические инструменты не должны создавать русскоязычные файлы без указания кодировки.
- Git должен корректно отображать UTF-8 текст.

## Причина

Контекст проекта является частью его ценности.

Повреждение текста означает частичную потерю памяти системы.

## Последствия

Положительные:

- единый стандарт;
- меньше скрытых ошибок;
- переносимость между системами.

Отрицательные:

- необходимо соблюдать правила создания файлов.
