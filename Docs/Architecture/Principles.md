# рхитектурные принципы eVo

## азделение ответственности

латформа разделяется на:

- Core — ядро системы.
- Modules — функциональные расширения.
- Interface — способы взаимодействия.
- eVo — интеллектуальная логика.
- Memory — внутренняя память системы.
- Workspace — данные пользователя.

## равила

1. Core не зависит от Interface.
2. Modules используют Core.
3. eVo использует Core, Modules и Memory.
4. Workspace принадлежит пользователю.
5. Memory принадлежит системе.
6. аждый компонент должен иметь понятное назначение.
