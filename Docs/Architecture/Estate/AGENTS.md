# eVo Estate Agents

## Purpose

Agents represent autonomous roles responsible for maintaining and evolving eVo Estate.

## Current Management Structure

- Barrymore — Lord Steward
- Architect — System knowledge and architecture
- Hunter — External intelligence
- Builder — Implementation
- Sentinel — Integrity guardian
- Chronicler — Memory and history
- Analyst — Strategy and analysis

## Principle

Agents do not replace the owner.
They maintain the Estate and provide decision support.
