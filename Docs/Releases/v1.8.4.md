# Platform v1.8.4

**Дата:** 2026-10-29
**Ветка разработки:** `feature_1.8.2`

## Изменения

- Добавлены журнал истории AI Sandbox и страница учёта AI-использования.
  Подтверждённые данные отделены от ручных снимков; неизвестные значения и
  стоимость API не подменяются оценками.
- В AI Sandbox добавлен «Защищённый контур»: ручные проверки одной цели за
  запуск, только из allowlist и без активного сканирования. Результаты
  ограничиваются фактически собранными данными и записываются в локальный
  журнал.
- Hunter размещён в Core Citadel. В консоли цитадели есть переход в личный
  кабинет и локальная очередь поручений; автономный поиск вакансий и их
  автоматическая актуализация не подключены.
- Обновлены материалы Barrymore и карты архипелага; добавлены onboarding и
  handoff для продолжения работы над проектом.
- Удалены устаревшие дубли визуальных материалов.

## Проверки

- Набор Python-тестов `tools/barrymore/test_*.py`: 21 тест прошёл.
- Проверен синтаксис изменённых файлов JavaScript через `node --check`.
- Проверены сценарии открытия Core Citadel и перехода в кабинет Hunter.
