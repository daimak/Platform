# Platform v1.8.3

**Дата:** 2026-10-29
**Ветка разработки:** `feature_1.8.2`

## Изменения

- Добавлено ручное обновление Morning Brief и автоматическая сверка источников
  при открытии дашборда. Повторный вызов LLM пропускается, если входные данные
  не изменились; ручное нажатие повторяет неудачный запрос к LLM.
- Локальный dashboard server запускается при входе пользователя в Windows,
  слушает только loopback и стартует без консольного окна.
- Задачи Barrymore получили постоянные записи и историю статусов. Пользователь
  может явно отметить задачу как Done; она остаётся в докладе 48 часов, затем
  переносится в архив с сохранением истории.
- Время доклада, событий и журнала сервера переведено на Ташкент (UZT, UTC+5).
- Созданы русская сводка Platform/eVo и Graphify-визуализация с JSON-данными и
  техническим отчётом.

## Проверки

- Проверены синтаксис Python, JavaScript и PowerShell.
- Проверены локальные endpoint дашборда, обновление статуса, кэширование
  Morning Brief и архивирование на временных тестовых данных.
- Проверен Windows logon task и доступность дашборда на `127.0.0.1:8765`.
