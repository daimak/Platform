# Операции Platform

Все команды выполняются относительно корня:

`C:\Work\Platform`

## Перейти в корень

```
cd C:\Work\Platform
```

## Посмотреть структуру

```
tree /F /A
```

Не сохранять дамп `tree` в корень. Живая карта репозитория: `Docs/Map.md`.

## Проверить RFC

```
dir RFC
```

## RULE: Root Drift

Если в структуре есть:

- `C:\Work\RFC`
- любые другие диски (`D:\`, `E:\`)
- папки вне Platform

это ошибка системы.

## RULE: Source of Truth

- точка входа: `README.md`
- файловая структура (как есть): `Docs/Map.md`
- изменения: `CHANGELOG.md`
- изменения дизайна: `RFC/`
