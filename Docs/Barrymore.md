# Баррримор — инструкция пользователя

Стюард Platform eVo. Отвечает за утренний доклад (Morning Brief) и хранит состояние системы.
Эта памятка — как пользоваться тем, что уже работает. Дата: 2026-10-25.

---

## Что умеет сейчас

1. **Morning Brief** — доклад по источникам истины: `Memory/Context/CURRENT.md` (фокус + следующий шаг), `Memory/Engineering/STATE.md` (ход инженерных работ), `CHANGELOG.md` (последние изменения), `Memory/Engineering/Tasks/` (статусы и история задач), git (ветка, коммит, чистота дерева).
2. **Доклад «с мозгами»**: кроме фактов, Баррримор получает текст источников локальной LLM (шлюз FreeLLMAPI, `http://localhost:31415/v1`) и пишет краткую сводку + предложение следующего шага. Модель — `auto` (шлюз сам выбирает свободную); можно зафиксировать в `Workspace/.env` переменной `FREE_LLM_MODEL` (например `fusion`).
3. **AI-статистика**: локальный журнал фиксирует usage из ответа FreeLLMAPI, если шлюз прислал счётчики; стоимость записывается только при явном значении от провайдера. Снимки Copilot, ChatGPT и других подписок/API пока вносятся вручную. Бэрримор читает сводку только по отдельному действию; включение её в Morning Brief выключено по умолчанию.

Времена доклада, событий и журнала сервера отображаются в часовом поясе Ташкента (UTC+5, UZT). Записи истории задач сохраняются в UTC.

## Где смотреть

- Один раз установить автозапуск локального сервера от имени текущего пользователя Windows:

  ```powershell
  powershell -ExecutionPolicy Bypass -File C:\Work\Platform\tools\barrymore\install-dashboard.ps1
  ```

  Установщик создаёт задание Windows Task Scheduler, которое запускает сервер при входе в систему, и запускает его сразу. Затем открыть `http://127.0.0.1:8765`; при каждом открытии страницы Barrymore проверяет источники. Сервер доступен только на этом компьютере. Чтобы удалить автозапуск:

  ```powershell
  powershell -ExecutionPolicy Bypass -File C:\Work\Platform\tools\barrymore\install-dashboard.ps1 -Uninstall
  ```
- **Плашка Баррримора** (верхний левый угол карты) — HTML-панель поверх чистого арта: портрет `assets/barrymore.png` (отдельный слой, готов к анимации), приветствие по времени суток и счётчик задач. Клик — открывает Morning Brief.
- Остров **AI Sandbox** содержит переход на страницу статистики AI, ручной ввод подтверждённых снимков и действие «Попросить Бэрримора проверить».
- Страница `http://127.0.0.1:8765/ai-usage.html` показывает только собранные/внесённые данные. GitHub Copilot и личная подписка ChatGPT не опрашиваются автоматически; лимиты, usage и подписочную плату нужно копировать из кабинета провайдера. Отсутствующее отображается как «Нет данных», не как ноль.
- Журнал хранится отдельно от репозитория в `%LOCALAPPDATA%\Platform\AI-Usage\usage.json`. Он не сохраняет полные prompts и ответы. Короткая сводка результата и пользовательское примечание обрезаются и проходят базовую маскировку распространённых форматов секретов; не помещайте туда чувствительные данные.
- Под плашкой появляется **ссылка «Review →»**, когда есть новый, ещё не открытый доклад. Открыли — ссылка исчезла до следующего доклада.
- Если LLM недоступен, в докладе будет блок «мозги недоступны», а ниже — обычные данные. Это не поломка.

## История задач

- Текущий список перенесён из `eVo/dashboard/tasks.js` в `Memory/Engineering/Tasks/Active/`. Каждая задача — отдельная JSON-запись с ID и историей переходов статуса.
- В Morning Brief задачу можно явно отметить как **Done**. Статус и время закрытия сохраняются в записи; Баррримор не определяет завершение автоматически.
- Done-задача остаётся в докладе 48 часов, после чего при следующей проверке задач переносится в `Memory/Engineering/Tasks/Archive/YYYY/MM/`. Открытый дашборд проверяет статусы раз в минуту; если он был закрыт, перенос произойдёт при следующем открытии. Запись вместе с историей сохраняется.
- `tasks.js` остаётся только запасным снимком для просмотра без локального сервера; источником истины является папка `Memory/Engineering/Tasks/`.
- Правила хранения и формат добавления задач: `Memory/Engineering/Tasks/README.md`.

## Как обновить доклад

```powershell
# Проверить источники; LLM вызывается только если значимые данные изменились
python C:\Work\Platform\tools\barrymore\morning-brief-agent.py

# только данные, без LLM (если шлюз не запущен)
powershell -File C:\Work\Platform\tools\barrymore\morning-brief.ps1
```
При ручной команде обновите страницу (F5). В запущенном дашборде источники проверяются при открытии страницы и кнопкой ↻; если входные данные не изменились, сохранённый доклад используется повторно без вызова LLM. Если предыдущая попытка завершилась ошибкой LLM, нажатие ↻ повторит попытку даже без изменений источников.

## Как сделать доклад содержательным

Доклад честен: в нём только то, что есть в источниках. Если `CURRENT.md` устарел — Баррримор прямо напишет, что данных о состоянии/деньгах/рисках нет. Правило простое:

> **Обновили CURRENT.md → перегенерировали бриф → в докладе появились факты.**

## Если что-то не так

| Симптом | Причина | Что делать |
|---|---|---|
| «Мозги недоступны» | не запущен шлюз FreeLLMAPI | проверить `http://localhost:31415/v1/models` в браузере |
| Дашборд не открывается по `127.0.0.1:8765` | сервер не запущен | проверить задание `Barrymore Dashboard Server` в Windows Task Scheduler или запустить `python C:\Work\Platform\tools\barrymore\dashboard-server.py` вручную |
| Страница открыта по другому порту (например `8014`) и без данных | на этом порту чужой статический сервер без Barrymore API | канонический адрес один — `127.0.0.1:8765`; владельца порта показывает `netstat -ano | findstr :8765`; второй экземпляр сервера не запустится — упадёт с «порт занят» |
| Доклад пустой по фактам | устарел `CURRENT.md` | обновить его и перегенерировать |
| Ссылка «Morning Brief» не появляется | доклад уже открывали | она показывается только для нового доклада |
| Данные без LLM устроили | — | пользоваться `morning-brief.ps1` |

## Безопасность

- Ключи лежат в `Workspace/.env` (не в Git) и в KeePassXC (`C:\Users\temp\Vault\Platform.kdbx`); в коде их нет.
- LLM **не имеет доступа к системе**: получает только текст, возвращает только текст (ADR-004).
- Сервер слушает только `127.0.0.1`; он отдаёт статические файлы и поддерживает только фиксированные операции обновления доклада, явной отметки задачи Done и чтения/записи AI-статистики.
- LLM не меняет задачи и не получает прямой доступ к ОС. Состояние задачи меняется только по явному нажатию пользователя и сохраняет историю.
- Журнал сервера: `%LOCALAPPDATA%\Platform\Barrymore\dashboard-server.log`.
- Сервер работает через `pythonw.exe`, а генератор и Git запускаются без отдельных консольных окон.
