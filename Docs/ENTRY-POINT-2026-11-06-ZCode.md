## Что делать

1. Открой канбан `GET http://127.0.0.1:8765/api/tasks` (или файлы `Memory/Engineering/Tasks/Active/*.json`).
2. Возьми ОДНУ карточку из списка ниже (свободную, без busy-лока) и работай по её description.
3. Взять задачу = захватить busy-лок:
   ```python
   import sys; sys.path.insert(0, r"C:\Work\Platform")
   from tools.lib.task_lock import acquire, heartbeat, release
   r = acquire("<task_id>", "<твоё имя агента>", "что делаешь")
   # ok:False → задача занята живым владельцем: НЕ ПРИСТУПАЙ, твой отклик уже
   # записан в Tasks/Busy/Claims/ — возьми другую карточку или работай над чем-то ещё.
   # Heartbeat обновляй при каждом шаге (или минимум раз в 5 минут), иначе лок
   # сочтут мёртвым и перехватят (TTL 600 c).
   release("<task_id>", "<твоё имя агента>")  # когда закончишь
   ```
4. Переводить карточку в «В работе»: `POST /api/tasks/<id>/stage/in-progress` с телом `{"by": "<твоё имя>"}`.
5. **Врата:** в «Проверку»/«Готово» тебя НЕ пустят (403) — готовность заявляет только владелец работы. Закончив, освободи лок, добавь комментарий карточке
   `POST /api/tasks/<id>/comments {"by": "<твоё имя>", "text": "готово: ..."}` — Sovereign примет работу утром.
6. Комментарии: `POST /api/tasks/<id>/comments` — пиши туда вопросы и статус. Отвечать будет Sovereign или вахтёр.
