# Что такое Platform

Platform — это система сохранения и восстановления контекста мышления.

Это не блокнот.
Это не менеджер задач.
Это не база знаний.

Главная задача Platform — помочь продолжить работу после любого перерыва.

---

# Где мы сейчас

Проект находится на этапе проектирования подсистемы **Memory**.

Сейчас строится фундамент всей системы.

До завершения Memory новые крупные подсистемы не добавляются.

---

# Что уже решено

* Platform хранит эволюцию понимания.
* Git хранит историю файлов.
* Memory хранит историю мышления.
* Новые сущности не добавляются, пока существующие полностью не поняты.

Capture → Session → Decision → Context → Snapshot
