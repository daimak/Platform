## Как кормить «мощные инструменты»

1. Чанк за раз: `chunks/jobs-0N.md` или `chunks/olx-autoservices-0N.md` + README
   (этот файл) как датасловарь. Токенов в чанке ~5–7K — влезает в любой чат.
2. CSV можно отдавать целиком (jobs.csv ≈ 110 KB) — для BI/Code Interpreter.
3. Просьба к экстракции формулировать как «верни JSON по схеме olx_structured» —
   сравнение прогонов позволит мерить согласованность экстракторов.
