## Порядок действий Дмитрия

1. Fiverr: профиль → 3 гига → отправить на модерацию (**таймер клиринга 14 дней стартует с первого заказа, не с регистрации — поэтому гиги вешать сегодня**).
2. Upwork: профиль → одобрение → первые пропозалы.
3. Скрины для галерей: открыть демо-Excel локально, снять 3 скрина (цены/колонки/итог); для гига 2 — скрин дашборда с витрины.
4. Вывод средств — условия в `channels.md` (Payoneer/USDT), заполнять «Withdraw» после первого заказа.
