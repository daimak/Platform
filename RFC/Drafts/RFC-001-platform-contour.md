# RFC-001: Границы контура Platform

Дата: 2026-10-25
Статус: Accepted (решения пользователя по пунктам 1–6, эта же дата)
Основание: аудит E-001/E-008 — `Memory/Engineering/FINDINGS.md` §7, §10

## Проблема

В одном репозитории смешаны четыре контура с разными владельцами и скоростью изменений:

1. сама система Platform/eVo;
2. пользовательские эксперименты (`Workspace/`);
3. чужой проект (`claude-chief-of-staff/`);
4. архивы и сгенерированные кэши (`Backup/`, `eVo/graphify-out/`, `*.backup`).

Это нарушало принцип «один репозиторий = одна система», раздувало клон (~30 МБ PNG) и порождало побайтовые дубли.

## Решение (принято и исполнено 2026-10-25)

1. `claude-chief-of-staff/` — вынесен за контур в `C:/Work/reference/`; gitlink удалён из индекса.
2. `Backup/` (PNG-архив визуалов) — вынесен в `C:/Work/Platform-archive/`; `eVo/dashboard/Backup/` (побайтовый дубль) — удалён.
3. `eVo/graphify-out/` — кэш, не отслеживается Git (пересобирается `graphify`); правило добавлено в `.gitignore`.
4. Удалены дубли: один из двух идентичных Handoffs (оставлен `HANDOFF-2026-07-08-eVo.md`), один из двух идентичных Archive CURRENT (оставлен `-before-refactor`), `tools/evo-save.ps1.backup`, `Workspace/.env.backup`. `Workspace/CURRENT.md` переименован в `notes-memory-design.md` — CURRENT в проекте один: `Memory/Context/CURRENT.md`.
5. `Interface/` (неиспользуемый Vue-шаблон, 173 пакета node_modules) — удалён; реальный UI — `eVo/dashboard/`.
6. ADR консолидированы в `Core/Architecture/ADR/` (ADR-001…005 + `INDEX.md`), ссылки на несуществующие ADR исправлены.

## Что НЕ выносится

Сама Platform не делится на несколько репозиториев (принцип P5 — минимизация сущностей). `Workspace/` остаётся пользовательской зоной внутри репозитория.

## Последствия

Репозиторий содержит одну систему; клон легче; ADR имеют единую нумерацию; документы (Map.md, README) обновлены. Ветвление/релизы — по D-002.
