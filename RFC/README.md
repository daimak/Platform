# RFC — предложения изменений

Значимые изменения Platform/eVo сначала описываются здесь, затем выполняются.

Назначение и правила каталога описаны в `Docs/Architecture/Structure.md` (раздел «RFC»).

## Структура

- `Drafts/` — черновики и активные предложения.
- `Accepted/` — принятые (переносятся из Drafts после решения пользователя).
- `Rejected/` — отклонённые (сохраняются с причиной).
- `Backlog/` — определённые, но отложенные идеи. Это не список задач.

## Формат RFC

```
# RFC-NNN: Название
Дата: YYYY-MM-DD
Статус: Draft | Accepted | Rejected | Backlog

## Проблема
## Решение
## Последствия
```
