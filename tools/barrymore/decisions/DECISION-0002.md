DECISION-0002
Date: 2026-07-13

Title: Стратегия версионирования eVo.

Status: Accepted

Decision
eVo использует формат версий:

MAJOR.MINOR.PATCH

Текущая версия:

eVo 0.1.0-alpha

Этапы развития:

0.x.x-alpha:
Фаза создания фундамента.
Архитектура может изменяться.

1.x.x:
Стабильная версия системы.

Изменение Major версии означает фундаментальное изменение системы.

Изменение Minor версии означает добавление значимой новой возможности.

Изменение Patch версии означает исправления, улучшения и техническое обслуживание.

Constraints
Автоматическое изменение версии на текущем этапе не используется.

Изменение версии требует явного решения.

Reason
Системе необходима понятная модель зрелости без создания лишней бюрократии на этапе формирования фундамента.
