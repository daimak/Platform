INITIATIVE-0001

Date: 2026-07-13

Title: Barrymore Live State View

Status: Proposed

Goal

Создать механизм, позволяющий Barrymore формировать актуальное представление состояния eVo на основе существующих источников данных.


Problem

Текущее состояние системы распределено между:

- tasks
- decisions
- reports

Человеку необходимо вручную собирать целостную картину.


Principles

- Источники данных должны иметь определённую структуру.
- Данные должны соответствовать правилам системы.
- Состояние должно вычисляться на основе источников истины.
- Не допускается создание дублирующего ручного состояния.


Success Condition

Barrymore способен показать актуальное состояние Platform без ручного формирования отчётов.


Tasks

Будут определены отдельно.
