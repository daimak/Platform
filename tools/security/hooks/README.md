# Pre-commit гейт секретов (V-09)

Хук `pre-commit` перед каждым `git commit` запускает `tools/security/secret_scan.py` и разбирает вывод:
**RED** (известные форматы ключей) — коммит отклоняется со списком файл:строка; **ORANGE** (похоже на секрет) — предупреждение, коммит проходит. Отчёты — `%LOCALAPPDATA%/Platform/SecurityReports/`.

**Fail-open:** поломка гейта не блокирует работу — если сканер не найден, упал или превысил
таймаут 60 с (процесс убивается), коммит проходит с пометкой `FAIL-OPEN` и причиной.

**Установка** (идемпотентно, чужой хук не затирает): `sh tools/security/hooks/install.sh`

**Отключить на один коммит:** `git commit --no-verify` (осознанный обход, не привычка).

**Ограничение:** сейчас сканируется всё дерево репо, а не только staged — медленнее, и известная
находка вне коммита (V-01) блокирует каждый коммит до ротации ключа. Фаза 2 — режим `--files`.
