# Инструменты безопасности Platform Evo (прототипы)

Дата: 2026-11-01. Статус: **прототипы для теста 02.11 под руководством Sovereign**.
Кнопки — во вкладке «Инструменты» модалки AI Sandbox (`/api/sandbox/*`).

## Состав

| Скрипт | Что делает | Наружу |
|---|---|---|
| `vuln_radar.py` | Радар уязвимостей: CISA KEV (факт эксплуатации) + EPSS (вероятность, api.first.org) + NVD API 2.0 (свежие критические). Воронка severity: KEV > EPSS ≥ 25% > CVSS 9+. | GET к публичным фидам (KEV кэшируется на 12 ч) |
| `port_audit.py` | Слушающие порты Windows (`netstat`/`tasklist`): красный — опасный порт на `0.0.0.0`/`::` (Docker 2375, Redis 6379, InfluxDB 8086, RDP 3389 и т.п.), оранжевый — незнакомое на wildcard, ожидаемые loopback-службы — `port_allowlist.json` | ничего |
| `secret_scan.py` | Регулярки по дереву репо: AWS/GitHub/Google/OpenAI/Slack/HF ключи, приватные ключи, общие присваивания. Найденное маскируется в отчётах | ничего |
| `nmap_probe.py` | Скан своих хостов (`-sV --version-light`, опц. `--script vulners` → CVE с CVSS). Цели вне loopback/приватных сетей — только с `--allow-external` | GET к vulners.com (при `--cve`) |

## Правила (не нарушаются прототипом)

- **Поводок:** никаких расписаний — запуск только кнопкой дашборда или рукой Sovereign.
- **Видимость песочницы:** отчёты пишутся в `%LOCALAPPDATA%\Platform\SecurityReports\` — **вне git и публичных data-файлов**; наружу уходят только пассивные GET к фидам, данные платформы не передаются.
- **Read-only:** инструменты ничего не меняют (ADR-003/004); запись — только свои отчёты в LOCALAPPDATA.
- Nmap — только по своим хостам; внешние цели = отдельное осознанное решение Sovereign.

## Запуск

CLI: `python tools/security/vuln_radar.py --days 7 --keywords windows,vmware,docker` (и аналогично остальные).
Дашборд: AI Sandbox → «Инструменты» → кнопки. API: `POST /api/sandbox/run {tool: radar|portaudit|secrets|nmap, args:[...]}`, статус `GET /api/sandbox/run-status`, последний отчёт `GET /api/sandbox/report?tool=radar`.

## Незакрытое (после теста)

- EUVD (ENISA): публичного API не нашли — подключить, когда документация появится (euvd-cli).
- NVD без API-ключа: 5 запросов/30 с — для радара хватает; при частых прогонах завести бесплатный ключ.
- Сикреты: список правил неполный (z.ai-ключи, шлюзовые токены) — расширять по находкам.
- Радар: не сопоставляет CVE с фактическим стеком хоста (следующий шаг — фильтр по установленному софту).
