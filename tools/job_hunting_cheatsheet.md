# Памятка: где и как искать работу/фриланс (DevOps и смежное)

Обновлено: 2026-10-29. Агрегатор: `tools/job_search.py` (дайджест раз в день — и половина «неизвестных площадок» приходит сама).

## 1. С этого начать сегодня (RU/UZ, минимум усилий)

| Где | Что делать |
|---|---|
| **hh.uz** | Сохранённые поиски «DevOps», «администратор Linux», «SRE» + email-уведомления. API уже в скрипте (403 с датацентрового IP, с домашнего работает) |
| **hh.ru** | То же + резюме открыть «для всех» — удалёнки из РФ в DevOps регулярно платят $2–4k |
| **Telegram** | Отдельная папка с каналами: @devops_vacancies, @remote_jobs_ru, @freelance_orders, @jobs_in_uzbekistan, @kwork_orders. Новые каналы искать на **tgstat.ru** (рейтинги → Работа) по словам devops, linux, freelance |
| **OLX.uz** | Раздел rabota: локальные заказы (боты, серверы, настройка). Скрипт тянет |
| **Habr Career** | Профиль + отклики; на хабре DevOps-вакансий много, конкуренция ниже, чем в разработке. ~~freelance.habr.com~~ — закрылся навсегда (проверено 30.10.2026) |

## 2. RU-фриланс площадки (создать профили за один вечер)

- **Kwork** — самый живой поток мелких/средних заказов; специализация «настроить CI/CD», «развернуть K8s», «наладить мониторинг» дефицитна
- **FL.ru** — крупнее заказы, но отклики резать без PRO
- **Workzilla** — быстрый вход, мелочь для рейтинга
- **Weblancer**, **Freelance.ru** — вторично, но профили пусть висят

## 3. Международный фриланс (английский, ставки в разы выше)

- **Upwork** — главный; раскачка профиля 2–4 недели, первые заказы дёшево ради отзывов
- Менее известные, но рабочие: **Arc.dev**, **Gun.io**, **Proxify**, **Lemon.io**, **Toptal** (жёсткий отбор, но и ставки), **Braintrust**, **Contra**, **Malt** (Европа), **CodeMentor** (консультации почасово — идеально для DevOps)

## 4. Remote-борды вакансий (если готов к найму, не только фриланс)

- RemoteOK, Remotive, WeWorkRemotely, Working Nomads, Jobspresso, JustRemote — все в скрипте или по RSS
- **Hacker News «Ask HN: Who is hiring?»** — 1-го числа каждого месяца, сотни вакансий с зарплатами; скрипт уже вытаскивает devops-комментарии

## 5. Как не упускать (метод)

1. **Скрипт раз в день** — `python tools/job_search.py`; можно повесить в cron/Task Scheduler и слать дайджест себе в TG-бота
2. **RSSHub на своём сервере** (есть же под шлюз) — превращает почти любую площадку (Kwork, FL, WWR) в RSS-ленту: `docker run diygod/rsshub`
3. **Алерты на каждой площадке** — сохранённый поиск + уведомление, не заходить «проверять»
4. **Прямой аутрич** — веб-студии и агентства на 5–20 разработчиков без DevOps in-house: письмо с 3 строчками «что починишь». Конверсия выше откликов на биржах
5. **Партнёрство с dev-шопами** — им DevOps нужен проектно; договорённость о % с проекта
6. **Профиль-визитка** — GitHub README + полстраницы лендинга: стек, кейсы, как связаться. Ссылку — во все профили

## Правило 80/20

Telegram-каналы + hh-алерты + Upwork дают 80% результата. Остальное — профили «пусть висят» и прямой аутрич раз в неделю.

# Под конкретный бэкграунд: 12+ лет enterprise DevOps (Сбер/Роснефть/X5/ВТБ)

Составлено 30.10.2026. Главный принцип: **не продавать часы, продавать пакеты**. DevOps плохо дробится на микрозаказы (подтверждено и рынком, и хабр-обзорами) — зато отлично продаётся как «проект под ключ» или «квота часов на месяц».

## Что продавать (пакеты, а не «настрою что-нибудь»)

1. **Аудит инфраструктуры за N дней** — отчёт + дорожная карта. Идеальный первый заказ: низкий риск для клиента, твой энтерпрайз-взгляд виден сразу.
2. **Kubernetes с нуля / миграция с VMware** — рынок вечный.
3. **CI/CD с нуля (GitLab CI / Jenkins → GitLab)**.
4. **Мониторинг под ключ**: Prometheus + Grafana + алертинг + дашборды.
5. **Тяжёлые хранилища** — твой козырь, которого почти ни у кого нет: планирование ёмкости, Ceph/HDFS/SAN, сотни PB масштаба. Консультации здесь дорогие и редкие.
6. **Вывод легаси EE-стеков (WebSphere/WebLogic) в контейнеры** — узкая ниша, конкуренции почти нет, страх у клиентов большой.
7. **Процессный энтерпрайз-бэкграунд** — change/CAB, инцидент-менеджмент, ИБ-требования (152-ФЗ, PCI DSS): для RU-корпоративных заказчиков это отдельный плюс, упоминать в откликах.

## Тир 2 — международные витрины (скрининг один раз, потом поток)

- **Upwork** — главный. Профиль: 3 кейса из энтерпрайза, английский B2+. Первые 2–4 недели тишина — норма; откликаться на свежие jobs (<24ч), первые заказы брать дёшево ради отзывов. Вывод из UZ: Payoneer.
- **Toptal** — жёсткий скрининг (язык + тесты + live-интервью), потом ставки $60–120+/час и enterprise-клиенты. Готовиться 1–2 недели, подавать заявку стоит сразу.
- **Proxify** — скрининг мягче Toptal, ставки $40–80/час, поток клиентов не мгновенный — профиль пусть живёт.
- **Lemon.io, Arc.dev, Gun.io** — пулы сеньоров под стартапы/СМБ; заявка + интервью.
- **Braintrust** — комиссию платит клиент; много enterprise-проектов.
- **Catalant** — консалтинговая биржа для энтерпрайз-экспертов: вот куда реально смотрят на «12 лет в больших корпорациях», а не на «настрою docker».
- **Malt** — если появится EU-резидентство/подключение.

## Тир 3 — контракты через борды (уже в скрипте)

WeWorkRemotely / RemoteOK / Remotive с фильтром «contract»; HN Who is hiring (роли с "contract/part-time"); Wellfound — fractional DevOps для стартапов.

## Тир 4 — прямые каналы (дают больше всех денег)

- **Бывшие коллеги** из Сбера/Роснефти/X5/ВТБ → «есть задача, возьмёшь субподряд?» — самый быстрый первый чек.
- **Аутсорс/аутстаф-конторы** без DevOps-практики — предложить себя как внешнего эксперта на проект.
- **LinkedIn** — профиль на английском + 3 кейса + открытость к contract.

## Первые 30 дней

1. Неделя 1: профили на 4 RU-биржи + Upwork; 3 кейса (PB-хранилище, EE→контейнеры, enterprise CI/CD); пакеты на Kwork.
2. Неделя 2: 10 откликов/день RU + 5–7 proposals Upwork (свежие вакансии!); заявки на Toptal/Proxify/Arc.
3. Недели 3–4: первые заказы дёшево ради рейтинга; параллельно аутрич бывшим коллегам. Дайджест площадок — раз в день через `tools/job_search.py`.

Ориентиры ставок: RU — 2–6 тыс ₽/час (кворки 0.5–5 тыс ₽/шт), международка — $40–90/час до первых отзывов, после Toptal/рейтинга — выше.
