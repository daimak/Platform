# eVo

Evolution Operating System.

## Purpose

eVo is a personal operating system designed to preserve context,
support decisions and increase human capability.

## Core Role

eVo Steward.

The Steward maintains:

- context
- memory
- system state
- direction

## First Interface

eVo Command Center.

A visual dashboard showing:

- current state
- attention points
- leverage actions
- evolution history
