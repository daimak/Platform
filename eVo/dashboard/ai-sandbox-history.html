КАК ЧИТАТЬ СВЕДЕНИЯ ОБ АВТОРСТВЕ

  • Пользователь задаёт направление, подтверждает решения и принимает результат.
  • Git надёжно показывает даты, файлы и коммиты, но большинство коммитов подписаны daimak. Это не доказывает, какой ИИ писал или проверял код.
  • Название модели фиксируется только там, где оно подтверждено. Неизвестного автора не угадываем; ниже приведены итоги работ, а не дословные переписки.
  • Проверка Gemini API 19 октября 2026 года подтверждает эксперимент с API, но не доказывает, что Gemini создавал код Platform.

ЭТАПЫ И РЕЗУЛЬТАТЫ В ПРОЕКТЕ

Июнь—июль 2026 Раннее развитие Platform/eVo. По Git установить конкретный ИИ нельзя. Основа eVo и панели управления, исполнитель задач Barrymore, интерфейс на русском и английском, протокол задач и документация. Коммиты f7c0982, 0b75c27, caf9213; автор Git — пользователь.

24—26 октября 2026 Архитектурная работа с помощью ИИ; в двух коммитах прямо упоминается совместная работа со «вторым ИИ», имя и модель неизвестны. Аудит контура, RFC-001, упорядочивание ADR и границ; утренний доклад Barrymore через локальный FreeLLMAPI; оформление Estate/Barrymore и Holmes Study. Коммиты fbffd54, 032eb57, cdbbebc, 0e454e1, 1168312, e054a7d.
29 октября 2026 Copilot SDK в VS Code — этот ассистент, работающий по указаниям пользователя. Доработки Barrymore и постоянной истории задач; локальный учёт использования ИИ; третий архипелаг Engine Core; маячки Estate/Maelstorm и визуальная доводка; краткая карта для следующего ИИ. Сверяйте фактический статус с Git и рабочим деревом: часть этого набора может быть не закоммичена.

РАБОТА ТЕКУЩЕГО АССИСТЕНТА · 29 ОКТЯБРЯ 2026

  • Утренний доклад: brief.js — генерируемый снимок window.EVO_BRIEF, а не отдельный текстовый отчёт и не сам генератор. Сборка выполняется через tools/barrymore/morning-brief-agent.py.
  • Barrymore: добавлено ручное обновление доклада, сокращены повторные вызовы языковой модели при неизменных источниках, настроен тихий запуск локального сервера loopback и постоянные записи задач с историей статусов и архивированием. Результат описан в Docs/Releases/v1.8.3.md, Docs/Barrymore.md и коммите 89038e8.
  • Учёт использования ИИ: локальный журнал и страница статистики в AI Sandbox, ручные снимки там, где поставщик не предоставляет доступные данные об использовании, отдельная сводка Barrymore и настройка включения в утренний доклад. Неизвестные данные об использовании и стоимости обозначаются как неизвестные, а не как нулевые; стоимость не вычисляется по числу токенов. Реализация находится в tools/barrymore/ai_usage.py, eVo/dashboard/ai-usage.*, tools/barrymore/dashboard-server.py и morning-brief-agent.py.
  • Визуальная карта: создан Engine Core Atoll на предоставленном изображении-образце; добавлен Trading Quarter для острова Estate без выдуманной функциональности; предложены исследовательские роли для пяти островов Maelstorm. Назначения новых островов — концепции, а не работающие подсистемы.
  • Маячки: обычные иконки сделаны полупрозрачными и возвращают полную непрозрачность при наведении. Изменения Maelstorm и CSS опубликованы коммитом ddd621b.
  • Передача контекста: создан Docs/AI-ONBOARDING.md с описанием каталогов, точек входа, проверок и предупреждением об устаревшей карте Docs/Map.md.

ПОДТВЕРЖДЁННЫЕ ИИ-СЕРВИСЫ

  • FreeLLMAPI — шлюз Barrymore к локальной языковой модели. Это компонент приложения, а не доказательство, что конкретный поставщик создал весь проект.
  • Gemini API — зафиксирован ручной эксперимент 19 октября 2026 года.
  • Второй ИИ — совместная проверка или работа явно упоминается в коммитах e47595e и e054a7d; поставщик и модель не указаны.
  • Copilot SDK в VS Code — ассистент, участвовавший в работе 29 октября 2026 года.
  • Подписки Copilot / ChatGPT — сведения об их лимитах можно внести в раздел учёта использования ИИ вручную. Это не подтверждает их участие в написании кода и не означает автоматического доступа к полной истории запросов.

ЧТО НАМЕРЕННО НЕ ЗАПИСЫВАЕТСЯ

Сырые запросы и ответы, секреты, личные данные, непроверенные названия моделей и выдуманные суммы. Для будущих работ добавляйте короткую запись: дата, ассистент/модель (только если известны), цель, принятый результат, ключевые файлы или коммит и способ проверки.
