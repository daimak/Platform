# SPEC верфи миров-draft (обязателен для каждого лейна)

## Что строим
Одна standalone-страница-превью мира для каталога вариаций четвёртого мира Platform. Это ВИТРИНА для выбора Sovereign: страница должна дать почувствовать мир за 5 секунд.

## Файл
- Путь: `C:\Work\Platform\eVo\dashboard\worlds-draft\<NN-slug>.html` (выдан в задании).
- Один HTML-файл, **всё инлайн**: `<style>` и `<script>` внутри. Никаких внешних файлов, CDN, шрифтов по сети, fetch — страница обязана работать офлайн (file:// и http://127.0.0.1:8765/worlds-draft/).
- **Общие файлы дашборда не трогать** (style.css, app.js, world-map.html и пр.) — только свой файл.
- Размер: 12–40 КБ.

## Шапка (обязательная)
```
[НАЗВАНИЕ МИРА крупно]        [чип-счётчики: 3–4 числа мира]      [⌂]
```
- Слева: название мира (русским, крупно), под ним ОДНА строка статуса: `ПРЕВЬЮ-ВАРИАЦИЯ · демо-снимок 09.11.2026` (это статус, не легенда).
- Справа: одна иконка-кнопка «⌂» → `index.html` (в каталог вариаций). Стиль кнопки: круглый, как иконки в шапках окон Platform.
- Чипы: маленькие подпись+число (пример: «острова 6», «маяки 9», «в море 2»). 3–4 штуки.

## Тело
- Композиция по концепту мира (острова, маяки, причалы, река, тучи...) — SVG/CSS-графика приветствуется. Пространство 1280×720 без горизонтального скролла.
- Минимум одна интерактивность: клик/hover по объекту → панель данных объекта (справа или снизу) меняется. Данные — из демо-снимка в задании.
- Каждому объекту-острову/сущности — осмысленное имя на русском.

## Демо-данные
- Только те, что даны в задании (они сняты с реальных систем Platform 08–09.11) + разумные правдоподобные производные. НЕ выдумывать лишние категории.
- Формат чисел: компактно (1 163M, 94,5%, 11 900). 

## Запреты (жёстко)
1. `user-select: none` — ЗАПРЕЩЁН. Текст выделяется везде.
2. Никаких легенд/инструкций («подсказка: кликните...» — запрещено). Только данные.
3. Канцелярит и ИИ-штампы («осуществляем», «качественно», «индивидуальный подход») — запрещены. Короткие живые фразы.
4. Эмодзи: максимум 1–2 на страницу, лучше ноль.
5. `alert/prompt/confirm`, внешние запросы — запрещены.
6. Неологизмы-загадки в названиях — запрещены (нормальный русский).

## Технические гочи
- JS простой и корректный: без фреймворков, слушатели на объектах, одна функция рендера панели. Проверь мысленно скобки/кавычки.
- Шрифты: system-ui/Segoe UI. Цифры моноширинно (font-variant-numeric: tabular-nums).
- Палитру используй свою (из задания) — но фон держи тёмным морским (~#0a1420 база, вариации по характеру мира).
- Контраст текста: не ниже 4.5:1.
