# ADR-004: Агенты не обращаются к ОС напрямую

Дата: концепция 2026-07; оформлена отдельным ADR 2026-10-25
Статус: Accepted

> До 2026-10-25 существовал только как строка внутри `eVo/scripts/bootstrap.ps1` (под именем ADR-0002). Оформлен файлом при консолидации ADR (см. `INDEX.md`).

## Решение

Агенты eVo не взаимодействуют с операционной системой напрямую.

Любое действие агента проходит через контролируемые инструменты (tools) с явными разрешениями.

## Последствия

- Права выдаются постепенно, по мере необходимости.
- Прямой доступ агентов к ОС считается нарушением границы безопасности.
- Локальный dashboard server является контролируемым tool: loopback-only, фиксированные
  маршруты, без произвольного выполнения команд. Чтение AI-статистики доступно
  через дашборд; ручные снимки и настройка включения в Morning Brief требуют явного
  действия пользователя. Обзор Бэрримора вызывается отдельно и не предоставляет
  агенту произвольного доступа к аккаунтам провайдеров или ОС.
