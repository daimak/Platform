# ADR-003: Barrymore read-only по умолчанию; изменения — через явные инструменты

Дата: концепция 2026-07; оформлена отдельным ADR 2026-10-25
Статус: Accepted

> До 2026-10-25 существовал только как строка внутри `eVo/scripts/bootstrap.ps1` (под именем ADR-0001). Оформлен файлом при консолидации ADR (см. `INDEX.md`).

## Решение

Barrymore (стюард eVo) читает состояние системы и не принимает решений о его
изменении самостоятельно.

Ограниченные записи разрешены только через фиксированные инструменты с явным
действием пользователя или утверждённой задачей (см. `tools/barrymore/TASK-PROTOCOL.md`).
В текущем дашборде это:

- генерация снимка Morning Brief в `eVo/dashboard/brief.js`;
- явное нажатие пользователем «Отметить Done», которое меняет только запись
  выбранной задачи в `Memory/Engineering/Tasks/` и сохраняет событие истории.

LLM не может самостоятельно закрывать задачи, выбирать произвольные файлы или
выполнять команды ОС.

## Последствия

- Дашборд не должен имитировать активное воздействие агента на систему.
- Все изменения проходят через узкие инструменты; статус Done требует отдельного действия пользователя.
- Отображаемые статусы агентов — статичные строки до появления реального runtime (аудит E-001, FINDINGS §9).
