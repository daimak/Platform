# ADR-005: Всё есть инструмент (Everything is a Tool)

Дата: концепция 2026-07; оформлена отдельным ADR 2026-10-25
Статус: Accepted

> До 2026-10-25 существовал только как строка внутри `eVo/scripts/bootstrap.ps1` (под именем ADR-0003). Оформлен файлом при консолидации ADR (см. `INDEX.md`).

## Решение

Любое действие, доступное агенту, оформляется как инструмент с описанным контрактом.

Нет «привилегированных» действий вне реестра инструментов.

## Последствия

- Новые возможности = новые инструменты, а не новые исключения.
- Аудит действий возможен по реестру инструментов.
